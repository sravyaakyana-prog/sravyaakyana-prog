### 🔎 SemanticRank AI

A full-stack semantic search system that retrieves and ranks relevant information using modern information-retrieval techniques.

**Key Features:**

* Generates semantic embeddings using Sentence-BERT
* Performs fast vector similarity search using FAISS
* Combines semantic retrieval with BM25 keyword search
* Uses a cross-encoder model to rerank retrieved documents
* Extracts grounded answers from the highest-ranked documents
* Supports user authentication and persistent search history
* Includes a React-based search interface and FastAPI machine-learning service

**Tech Stack:**
React, Vite, Tailwind CSS, Node.js, Express.js, FastAPI, Python, MongoDB, Sentence-BERT, FAISS, BM25, Cross-Encoder
