### 🔎 SemanticRank AI

A full-stack semantic search system that retrieves, ranks, and evaluates relevant information using modern information-retrieval techniques.

**Key Features:**

* Generates semantic embeddings using Sentence-BERT
* Performs fast vector similarity search using FAISS
* Combines semantic retrieval with BM25 keyword search
* Uses cross-encoder reranking to improve result relevance
* Evaluates retrieval performance using NDCG, Precision, Recall, MAP, and MRR
* Supports authentication and persistent user search history
* Includes a React frontend and FastAPI-based machine-learning service

**Tech Stack:**  
React, Vite, Node.js, Express.js, FastAPI, Python, MongoDB, Sentence-BERT, FAISS, BM25, Cross-Encoder, Docker

🔗 **Repository:** [SemanticRank AI](https://github.com/sravyaakyana-prog/Semantic-rank-search-system)  
🌐 **Live Demo:** [semantic-rank-search-system.vercel.app](https://semantic-rank-search-system.vercel.app)
